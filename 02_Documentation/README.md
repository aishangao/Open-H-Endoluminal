V0.1 | Status: Planning

本目录存放跨 WP 的系统说明、接口基线和决定记录；不存放控制程序、原始实验数据或硬件设计文件。

- [SYSTEM_ARCHITECTURE.md](SYSTEM_ARCHITECTURE.md)：系统层级与职责关系；不批准具体软件架构。
- [INTERFACES.md](INTERFACES.md)：输入、指令、测量状态与派生数据的语义和待定接口。
- [DECISIONS.md](DECISIONS.md)：真正已确认的项目组织决定及独立列出的 Open/TBD 事项。
- [PROJECT_PLAN.md](PROJECT_PLAN.md)：简要记录项目的阶段计划、时间安排和进展。

WP12 负责跨模块一致性，各相关 WP 随材料变化更新接口和架构说明。具体成果位置见 [Repository Map](../README.md)。
