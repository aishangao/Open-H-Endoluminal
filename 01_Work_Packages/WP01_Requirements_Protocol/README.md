# WP01 - Requirements and Collection Protocol

V0.1

## Objective

将 Proposal 的下消化道导航目标转化为可追踪的采集需求和协议。

## Scope

定义 lumen alignment、advancement、designated-region observation 和 withdrawal；不在此设计驱动实现。

## Key Requirements

分别统计 phantom 4 h 与 ex-vivo 4 h 可用同步数据；排除准备、重置和不可用记录。每种场景计划约 50% translation-dominant、50% articulation-requiring trajectories。

## Dependencies & Interfaces

输入为 Proposal；向 WP08 提供场景协议，向 WP09 提供任务语义，向 WP10 提供验收需求，向 WP12 提供里程碑基线。

## Expected Deliverables

需求追踪表、采集协议草案、任务与可用时长定义；成果归入 02_Documentation 和 05_Experiments。

## Open Questions

可用片段判定阈值、单 episode 边界和责任人 TBD。
