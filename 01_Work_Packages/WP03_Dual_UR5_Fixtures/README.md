# WP03 - Dual UR5 and Fixtures

V0.1

## Objective

规划 dual-arm UR5 对外部内窥镜组件的插入、回撤和支撑。

## Scope

一臂驱动 insertion，另一臂支撑或定位近端组件；只描述外部夹具运动。

## Key Requirements

规划兼容夹具姿态与轴身弯曲约束，采集前检查稳定性和行程；不得将夹具位移视为已验证腔内插入深度。

## Dependencies & Interfaces

接收 WP02 组件几何需求，与 WP04 对接运动指令，与 WP05 对接安全约束，与 WP07 对接 tool/fixture frames。

## Expected Deliverables

夹具需求、装配与坐标参考说明、后续稳定性验证记录；设计放 03_Hardware，证据放 07_Tests_QA。

## Open Questions

夹具几何、机器人控制模式、坐标系、支撑协调方法和行程 TBD。
