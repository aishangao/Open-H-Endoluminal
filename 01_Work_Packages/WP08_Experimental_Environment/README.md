# WP08 - Experimental Environment

V0.1

## Objective

规划可重复 phantom 布局和 ex-vivo porcine colon 采集条件。

## Scope

覆盖 bent、looped、tortuous phantom configurations，组织准备、配置记录与实验流程；不开展患者操作。

## Key Requirements

记录 configuration/specimen ID、基本准备信息和 operator code/experience；组织仅在状态支持任务时使用，采集前落实适用机构审批及来源、处理和处置程序。

## Dependencies & Interfaces

接收 WP01 协议与 WP05 安全约束；向 WP06、WP09 和 WP11 提供配置、组织和场景元数据。

## Expected Deliverables

场景配置说明、准备与处置协议、后续 session records；文档放 05_Experiments，受限信息留在获批存储。

## Open Questions

组织供应、审批状态、布局尺寸、组织可用状态标准及日程 TBD。
