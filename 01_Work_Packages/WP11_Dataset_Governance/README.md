# WP11 - Dataset Packaging and Governance

V0.1

## Objective

规划 LeRobot-compatible delivery、权利审查、隐私及发布治理。

## Scope

覆盖 dataset metadata、provenance、licensing、de-identification、标定及平台描述；本任务不上传或发布数据。

## Key Requirements

Proposal 计划以 OpenMDW-1.1 发布获准数据并贡献至 HuggingFace；发布前核实视频、日志、标注、标定与第三方描述的分享权。默认不录音，operator 使用 study codes，原始数据置于机构获批存储。

## Dependencies & Interfaces

接收 WP07 标定、WP08 场景/审批信息、WP09 标注与 WP10 QA；向 WP12 提供交付就绪状态。

## Expected Deliverables

LeRobot 字段映射、dataset description、权利与排除项清单、发布审查材料；文档放 02_Documentation，导出布局见 06_Data。

## Open Questions

LeRobot 版本/schema、存储权限、机构隐私要求、再分发限制及发布审批 TBD；代码仓库许可另行决定。
