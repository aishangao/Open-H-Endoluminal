# WP05 - Safety and Operational Constraints

V0.1

## Objective

明确人员、机器人、夹具和内窥镜在采集过程中的安全约束及授权边界。

## Scope

覆盖 operator enable、emergency stop、运动限制与实验前检查；不宣称已有安全认证。

## Key Requirements

Proposal 包含 bounded steering、enable 与 emergency stop；物理动作和潜在危险实验需明确授权及适用程序，能力必须通过证据确认。

## Dependencies & Interfaces

约束 WP02–04 的机械及控制设计；与 WP08 对接实验流程，与 WP10 对接验证证据。

## Expected Deliverables

风险与约束清单、停止行为需求、操作检查表及后续验证记录；归入 02_Documentation、05_Experiments 和 07_Tests_QA。

## Open Questions

停止链路、故障响应、速度/力/行程限值、监督职责及验收标准 TBD。
