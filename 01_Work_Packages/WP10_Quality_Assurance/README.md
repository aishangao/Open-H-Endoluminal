# WP10 - Quality Assurance

V0.1

## Objective

建立 usable synchronized hours 与交付质量的可追溯验证依据。

## Scope

覆盖流完整性、时间戳、video/log 时长、画质、对齐及标签抽查；不以计划代替测试证据。

## Key Requirements

每次 session 前检查 video 与必需控制/状态通道；剔除不可用记录，分别报告 phantom 和 ex-vivo 保留时长，记录实际 rates、gaps 和 dropped samples。

## Dependencies & Interfaces

依据 WP01 需求检查 WP06 采集、WP07 对齐和 WP09 标注；向 WP11 提供质量报告，向 WP12 反馈进度风险。

## Expected Deliverables

验收检查清单、后续 QA 报告、缺陷与可用时长统计；放 07_Tests_QA。

## Open Questions

画质与对齐阈值、抽检比例、时长计算规则和签署责任 TBD。
